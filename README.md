# Scenes: A Club Management System (CMS)

Scenes is intended for use in highschools, college campuses, or local communities to help them pull "scenes" or events.

Scenes allows club managers to onboard new members, manage inventory, assign tasks, log club expenses, splitwise functionality to organise meetups at restaurants, and an event management portal for clubs to announce their events.

Built as part of Hackclub's [Stardance](https://stardance.hackclub.com/)!
